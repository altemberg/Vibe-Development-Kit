# Vibe Development Kit (VDK)

VDK is an AI-first development methodology and repository blueprint for building modern software with a frontend-first, card-based, human-orchestrated workflow.

## Core Principles

- Frontend First
- Mock Data First
- Test Critical Flows
- Reuse Before Create
- Rule of Three
- English Only Codebase
- Card-Based Worktrees
- Minimal Agent Handoffs
- Human-Orchestrated AI Workflow

## Recommended Flow

1. Create a card
2. Run Product Manager / Analyst / Spec Writer when needed
3. Create architecture notes for medium/large cards
4. Build frontend with realistic mock data
5. Add tests for critical flows
6. Implement backend only after UI approval
7. Review code
8. Update docs, changelog, and PR summary

## Repository Structure

```txt
agents/           Role-based agent personas
cards/            Work units / feature cards
artifacts/        Inputs and outputs generated by agents
docs/             Product, architecture, testing and ADRs
templates/        Reusable templates
.claude/          Claude commands and worktree metadata
```
